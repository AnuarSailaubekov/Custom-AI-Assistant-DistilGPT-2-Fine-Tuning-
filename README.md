Кастомный AI-ассистент на базе DistilGPT-2

В этом проекте реализован законченный цикл дообучения (fine-tuning) легковесной генеративной языковой модели на пользовательском наборе диалоговых данных с последующим развертыванием локального веб-интерфейса. Основная цель работы — освоить и продемонстрировать полный практический путь работы с моделями обработки естественного языка (NLP) без использования сторонних облачных API: от очистки и форматирования входных данных до обучения весов и фильтрации инференса.
В качестве базы выбран компактный чекпоинт distilgpt2 от Hugging Face. Обучение осуществляется на диалоговом датасете в формате JSONL с маскированием токенов выравнивания (padding) для точного расчета функции потерь (Cross-Entropy Loss). За счет этого модель не заучивает служебные токены и генерирует связный текст. Интерфейс общения с пользователем построен на фреймворке Gradio и дополнен алгоритмом постобработки, который отсекает незавершенные фразы строго по знакам препинания, избавляя ответы от лишних хвостов и артефактов генерации.
Стек технологий: Python, PyTorch, Hugging Face Transformers & Datasets, Gradio.

Структура репозитория включает в себя:
* data/data.jsonl — обучающая выборка пар «вопрос-ответ»;
* train_ai.py — скрипт подготовки данных, токенизации и запуска обучения модели;
* chat_ai.py — скрипт инференса с локальным веб-сервером Gradio и постобработкой;
* requirements.txt — список необходимых Python-библиотек;

Инструкция по запуску:
1. Установите зависимости: pip install -r requirements.txt
2. Запустите обучение модели: python train_ai.py
3. Откройте чат-бот в браузере: python chat_ai.py
